# 연구 메모 (가상 연구, 스킬 시험용)

- 주제: 소형 한국어 리랭커(0.5B)의 미세조정에서 하드 네거티브 비율이 검색 정확도에 주는 영향
- 동기: RAG 서비스에서 재순위기는 지연 예산이 작아 소형 모델을 씀. 하드 네거티브를 많이 넣으면 좋다는 통념이 있으나 소형 모델에서는 확인된 바 없음
- 기존 연구: 대형 리랭커(7B 이상)에서 하드 네거티브 비율을 높일수록 MRR이 오른다는 보고 2건(가상 [3],[4]). 소형 모델 대상 연구 없음. 거짓 음성(false negative) 문제를 지적한 연구 1건([5])
- 방법: 같은 0.5B 체크포인트를 하드 네거티브 비율 0%, 25%, 50%, 75%로 미세조정. 시드 3개씩. 평가는 공개 한국어 검색 벤치마크 2종(KoMS, KoNQ, 가상)과 사내 로그에서 만든 보류 세트 1,200질의
- 결과 1: 25%까지는 MRR@10이 오름(KoMS 0.612→0.648, KoNQ 0.574→0.601). 50% 이상에서는 다시 떨어짐(75%에서 KoMS 0.603). 시드 간 표준편차 0.004 이하
- 결과 2: 75%에서 떨어지는 원인을 보려고 하드 네거티브 300개를 사람이 검수함. 그중 31%가 실제로는 정답(거짓 음성). 거짓 음성을 걸러낸 뒤 75%로 다시 학습하면 KoMS 0.651로 25%와 비슷해짐
- 결과 3: 보류 세트에서도 같은 경향(25%가 최고, 0.702). 지연은 모든 조건에서 같음(질의당 11ms, 모델 크기가 같으므로)
- 한계: 모델 1종, 언어 1종, 하드 네거티브 채굴기 1종. 사람 검수는 300개만
- 결론: 소형 리랭커에서는 하드 네거티브 비율보다 거짓 음성 제거가 먼저임. 25% 근처가 실용적 기본값
