# 한국어 학술논문 쓰기

## 개요

- 기준: 2024년 KCI 등재 학술지 AI 논문 5편의 전개와 문체(reference/corpus.md). 측정값은 scripts/ko_style_check.py가 같은 방식으로 잼
- 핵심 원칙: 영어 초안의 문장 경계, 시제, 담화 표지를 옮기지 않음. 문단마다 주장을 뽑아 아래 장별 순서와 문장 틀로 다시 씀
- 적용: 초록, 본문, 결론, 요약 쪽(학술논문체 "~이다, ~한다, ~하였다"). 제외: 표·그림 안 문구와 캡션(개조체), 영문 원고

## 작업 순서

1. 원천(영문 초안, 개조체 메모, 결과 수치)을 문단별 주장 목록으로 바꿈. 수치는 한 출처(결과 파일)에서만 가져옴
2. 장별 구성표의 순서로 문단을 배치함. 원천에 없는 내용(관련 연구 장, 향후 연구, 표의 빈 칸)은 만들지 않음
   - 원고가 논문 전체이면 구성 안내 문단을 씀. 일부 장만 있는 부분 원고이면 구성 안내 자리에 "확정 필요"만 둠
   - 표의 빈 칸은 표 안에 "확정 필요"로 둠
   - 원천끼리 수치나 서술이 어긋나면 한쪽으로 고치지 않고 원고 끝 "확정 필요 사항"에 적음
3. 문장 계약에 맞춰 씀. 영문 초안이 있으면 대응표로 담화 표지를 바꿈
4. `python scripts/ko_style_check.py 원고파일`(.tex/.md/.txt)을 실행함
   - 문장 60개 이상(논문 전체): "낮음"·"높음"으로 나온 지표를 고침
   - 문장 60개 미만(부분 원고): 번역투 표지와 LLM 어휘만 고치고, 비율 지표는 참고만 함. 결과 장 위주의 부분 원고는 과거형·결과 동사 비율이 원래 높게 나옴
5. 초록·본문·결론의 수치와 용어가 같은지 대조함

## 장별 구성

| 장 | 문단 순서(기능) | 대표 틀 | 시제 |
|---|---|---|---|
| 초록(1문단, 6~9문장) | 배경 → 문제·공백 → 목적 → 방법 → 결과(수치) → 의의 | "본 논문에서는 ~을 분석한다.", "~을 산출하였다.", "~이 가장 높은 상관관계를 보였다." | 목적·의의 현재, 수행·결과 과거 |
| 서론(4~6문단) | 배경(정의나 분류로 시작) → 기존 접근과 한계 → 공백 → 목적과 방법 개요 → 기여 → 논문 구성 | "~한 연구는 아직 미흡한 실정이다.", "본 논문의 기여는 다음과 같다. 첫째, ~하였다.", "2장에서는 ~을 살펴보고, 3장에서는 ~을 설명한다." | 배경 현재, 선행연구 사건 과거, 기여 과거 |
| 관련 연구 | 주제별 문단: 정의 → 연구[n]이 한 일 → 한계 → 끝 문단에서 본 연구의 위치 | "논문 [10]에서는 ~을 제안하였다.", "그러나 ~한다는 한계가 있다.", "본 연구는 ~라는 점에서 이들 연구와 다르다." | 정의·한계 현재, 개별 연구 과거 |
| 방법·실험 설정 | 장 도입 → 구성 요소 → 데이터·지표 → 설정값 | "본 장에서는 ~을 설명한다.", "~이라 칭한다.", "~로 설정하였다." | 시스템 동작 현재, 실험에서 한 선택 과거 |
| 결과 | 표·그림 지칭 → 수치 관찰 → 대조 → 원인 해석 | "표 1은 ~을 나타낸다.", "A는 B에 비해 ~ 높은 성능을 보였다.", "반면, ~", "이는 ~ 때문으로 보인다." | 표 설명 현재, 관찰 과거, 해석 추정 |
| 결론 | 요약 → 주요 수치 → 의의 → 한계 → 향후 연구 | "본 논문에서는 ~을 분석하였다.", "~는 점에서 의의가 있다.", "다만 본 연구는 ~에 한정된다.", "향후 연구에서는 ~할 계획이다." | 요약 과거 |

장별 원문 예문은 reference/phrasebank.md 1~6절에 있음. 새 기법 제안, 실험 설계·통제, 반복 실험, 유의성 검정, 신뢰구간, 차이 없음, 조건부 효과·상호작용, 어블레이션, 사전 판정 기준을 쓰는 문장은 phrasebank 8절의 틀로 씀.

## 문장 계약

| 항목 | 계약 | 기준 범위 |
|---|---|---|
| 길이 | 한 주장을 이루는 영어 두세 문장은 연결 어미(-며, -고, -으나, -므로, -어)로 한 문장으로 합침 | 중앙값 68~79자 |
| 시제 | 자기 실험의 수행·관찰은 "~하였다", 표 설명과 일반 사실은 현재형. 과거형은 "~하였다"로 통일 | 실험 논문 과거형 종결 31~44%, 현재형 29~40% |
| 잇기 | 서너 문장에 한 번은 "이는, 이러한, 이를 통해" 또는 "또한, 특히, 반면, 그러나"로 앞 문장을 받음 | 문두 지시어 8~23%, 접속어 10~20% |
| 주어 | "본 논문에서는"과 "본 연구에서는" 중 하나로 통일. "우리는"은 쓰지 않음 | |
| 용어 | 초록과 본문에서 각각 첫 등장 때 한 번 "한글 용어(English term)" 또는 "한글 용어(English term, 약어)"로 병기하고, 그 뒤로는 한글만 씀. 뜻풀이는 괄호 안 콜론 대신 별도 문장 "~이란 ~을 의미한다." | 병기 65~294/1000문장 |
| 연구 질문 | 의문문 대신 "본 논문은 ~인지와 그 원인을 분석한다." | |
| 결과 동사 | "보였다, 나타났다, ~임을 알 수 있다, ~을 확인할 수 있다". 하한만 확인함 | 15/1000문장 이상(기준 논문 16~81) |
| LLM 연관 어휘 | 시사한다, 규명, 확인되었다, 구조적, 핵심, 이러한 결과는, 단순한 X를 넘어: 장마다 1회 이하 | 0~59/1000문장 |
| 통계 표기 | 반복 수와 ±의 뜻(표준편차, 시드 n)을 설계 문장에 한 번 밝힘. 백분율 지표의 차이는 %p. 검정 결과와 신뢰구간은 점추정 바로 뒤 괄호에 넣음: "(t = 3.93, p < 0.05)", "+3.8점(95% 신뢰구간 [2.6, 5.0])". 한 논문 안에서 한 형식으로 통일 | phrasebank 8.3절 |
| 근거 강도 | 결과 동사는 근거 수준에 맞춤: 검정·신뢰구간으로 0을 배제했을 때만 "유의하게", 신뢰구간이 0을 포함하면 "유의한 차이는 없었다"(효과 없음으로 단정하지 않음), 원인을 통제 실험으로 분리했을 때만 "입증", "필수적" | phrasebank 8.7절 강도표 |

수치는 scripts/ko_style_check.py와 reference/corpus.md 3절이 같은 측정값을 씀. 스크립트의 판정 범위는 이 값을 바깥쪽으로 반올림한 것임.

## 영문 초안 담화 표지 대응표

| 영문 초안 | 직역하면 | 한국어 논문 틀 |
|---|---|---|
| Our findings: (불릿) | 주요 결과는 다음과 같다. + 단문 불릿 | 본 논문의 기여는 다음과 같다. 첫째, ~을 보였다. 둘째, ~ |
| Does X hold for Y? And why? | ~는 성립하는가? 그 원인은 무엇인가? | 본 논문은 X가 Y에서도 성립하는지와 그 원인을 분석한다. |
| The practical rule is simple: do X. | 실무 지침은 단순하다. X해야 한다. | 이상의 결과는 ~에서 X를 먼저 수행하여야 함을 보여 준다. |
| So A is not the problem; B is. | 즉, 문제는 A가 아니라 B이다. | 이는 성능 하락이 A보다 B에 기인함을 의미한다. |
| X helps only when Y. | X는 Y일 때만 도움이 된다. | X의 효과는 Y인 조건에서 유의하게 나타났고, 다른 조건에서는 유의한 차이가 없었다. (두 조건의 효과가 다르다고 쓰려면 상호작용을 따로 보고함, phrasebank 8.5절) |
| Table 1 shows the results. | 표 1은 결과를 보여 준다. | 표 1은 ~ 조건별 ~을 나타낸다. |
| As expected, ... | 예상대로 ~ | ~이므로 ~는 변하지 않았다. |
| This matches [5]. | 이는 [5]와 일치한다. | 이는 [5]에서 보고된 ~와 일치하는 결과이다. |
| We leave X to future work. | X는 향후 과제로 남긴다. | 향후 연구에서는 X를 수행할 계획이다. |
| Limitations: a, b, c. | 한계: a, b, c. | 본 연구는 a와 b에 한정되며, c라는 한계가 있다. |

## 흔한 실수

- 기준 논문에서도 나온 결함(의미 중복, 주술 호응, 이유절 중복, "~에 의해" 피동, "~시키다" 남용, 용어·수치 불일치, 본문 개조식 불릿)은 reference/phrasebank.md 7절의 고친 형태로 씀
- 끝맺음만 "~함"에서 "~한다"로 바꾼 개조체 원고는 문장 길이·잇기 지표가 모두 낮게 나옴. 끝맺음 교체가 아니라 3단계(문장 계약)부터 다시 씀
