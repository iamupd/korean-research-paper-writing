# 분야 프로필

- 기준 말뭉치 30편(reference/corpus.md 7절)을 6개 분야로 나누어 관찰한 장 구성, 문장 관례, 수치임
- 분야마다 5편이라 관례는 "이 5편에서 관찰된 것"임. 투고처 집필 요령이 다르면 집필 요령을 따름
- 괄호 안 ID는 관찰한 논문임

## 1. 분야 판별

| 프로필 | 연구 대상과 방법 | 기준 논문의 투고처 |
|---|---|---|
| ai | AI 모델 자체(학습, 데이터셋, 평가, LLM 활용 기법) | 정보과학회논문지, 정보처리학회 논문지, 지능정보연구 |
| cs | AI 이외 컴퓨팅 시스템의 구현과 측정(하드웨어 가속, 스토리지, 가상화 네트워크, 보안 분석, 스케줄링) | 정보보호학회논문지, 정보과학회논문지, 정보처리학회 논문지 |
| ee | 전자파·레이다 하드웨어의 설계와 측정, 전력 계통 최적화, 통신·메시징 시스템 실험 | 한국전자파학회논문지, 전기학회논문지, 한국통신학회논문지 |
| me | 기계·로봇 시스템, 화공 공정과 소재 합성, 토목 구조 해석 | 한국정밀공학회지, 화학공학, 대한토목학회논문집 |
| sci | 물리·화학·생명 현상의 실험(합성, 소자 특성, 세포 실험) | 새물리, 전기화학회지, 생명과학회지 |
| data | 통계 방법과 모의실험, 실제 자료의 실증 분석, 산업공학 최적화·시뮬레이션 | 응용통계연구, 한국산업경영시스템학회지, 품질경영학회지 |

- 연구 대상이 AI 모델이면 ai, AI를 도구로만 쓰면 연구 대상의 분야로 고름(예: 사출 공정을 머신러닝 예측 모형과 베이지안 최적화로 다룬 D3은 data)
- 두 분야에 걸치면 결과 장이 주로 보고하는 것(측정값, 모형 성능, 시스템 성능)으로 고름
- 애매하면 `--field` 없이 공통 범위로 점검하고, 그 사실을 사용자에게 알림
- 인문학(각주 인용, 한자 병기, 원전 해석), 교육 연구, 임상 의학은 측정하지 않은 분야이므로 이 스킬의 범위 밖이라고 알림

## 3. 분야별 장 구성과 문장 관례

### ai (P1~P5)

- 장 구성: 서론 / 관련 연구 또는 이론적 배경 / 방법·데이터셋 구축 / 실험 환경 / 실험 결과(어블레이션 포함) / 결론 (P3, P4, P5)
- 문장 틀은 SKILL.md 장별 구성표와 reference/phrasebank.md 1~6절에 있음(이 분야에서 뽑음)

### cs (C1~C5)

- 장 구성: 서론 / 배경지식(및 관련 연구) / 제안 설계·구현 / 실험 결과 또는 성능 평가 / 결론(및 향후 계획) (C1, C2, C5). 관련 연구를 성능 평가 뒤에 두기도 함(C3)
- 정보보호학회논문지는 장 번호를 로마 숫자로 씀(C1, C4)
- 결과 문장: "~ 조건에서 A가 B보다 ~% 감소한 것을 확인할 수 있다"처럼 비교 대상과 증감률을 함께 쓰는 현재형 "확인할 수 있다"가 많음(C1, C3)
- 도구와 환경: "~을 사용하여 ~을 확인하였고, ~을 위해 ~을 사용하였다"처럼 이름과 용도를 함께 씀(C4)
- 현재형 비율이 가장 높고(중앙값 42%) 과거형이 가장 낮음(15%). 시스템 동작을 현재형으로 서술하는 비중이 큼

### ee (E1~E5)

- 하드웨어 설계·측정(한국전자파학회논문지): Ⅰ. 서론 / Ⅱ. 설계(및 제작·검증) / Ⅲ. 제작 및 성능 측정 / Ⅳ. 결론 (E1, E4)
- 전력 계통 최적화: 서론 / 수리적 모델 정식화 / 사례연구 / 시뮬레이션 결과 및 분석 / 결론 (E5)
- 반복 측정: 횟수와 대표값을 한 문장에 씀. "~을 총 n회씩 측정하였으며, 평균값·최대값·최소값을 그림 N과 같이 나타내었다"(E1)
- 사례연구: 대상과 기간을 먼저 정함. "본 연구는 ~ 계통을 대상으로 ~부터 ~까지를 계획기간으로 설정하였다"(E5)
- 해석: "~로 인하여 발생한 것으로 보인다", "~은 개선된 것으로 판단된다"(E1, E5)

### me (M1~M5)

- 화공·소재(화학공학): 1. 서론 / 2. 실험 / 3. 결과 및 고찰 / 4. 결론 (M2, M5). 결과와 해석을 한 장에서 함께 씀
- 기계: 서론 / 연구방법 / 결과 / 논의 / 결론 (M1), 또는 서론 / 문제 정의 / 시스템 설계 / 실험 결과 / 결론 (M4)
- 토목 구조: 서론 / 재료·부재 특성 / 유한요소해석(설계, 해석, 결과) / 결론 (M3)
- 결과: 그림을 먼저 지칭함. "~을 확인하기 위해 Fig. 2에 ~ 분석 결과를 나타내었다"(M2). 그림·표 번호는 영문(Fig., Table)으로 씀(M2, M4, M5)
- 시료와 조건: 온도·시간·순도를 숫자로 씀. "~ ℃에서 ~시간 동안 탄화시켜 ~을 제조하였다", "순도 99.95% 이상의 ~을 사용하였다"(M2, M5)
- 해석: "~에 기인하는 것으로 보인다", "~으로 인한 것으로 판단된다"(M2, M5). 후속 과제: "~하는 추가 연구가 필요할 것으로 사료된다"(M4)

### sci (N1~N5)

- 물리(새물리): Ⅰ. 서론 / Ⅱ. 실험 방법 / Ⅲ. 결과 및 분석(또는 논의) / Ⅳ. 결론 (N1, N4)
- 화학(전기화학회지): 1. 서론 / 2. 실험 / 3. 결과 및 고찰 / 4. 결론 (N2, N5)
- 생명(생명과학회지): 서론 / 재료 및 방법 / 결과 / 고찰. 방법의 소제목으로 측정 항목 이름("ATP 농도의 측정", "반응성 산소종의 측정")을 붙임(N3)
- 장비와 시약: 모델명·제조사·국가를 괄호에 넣음. "저항 측정기(모델명, 제조사, 국가)를 사용하여 ~을 측정하였다"(N2)
- 측정 결과: 과거형 비율(중앙값 54%)과 문장 길이 중앙값(94자)이 6개 분야 중 가장 큼. 처리 조건에 따른 변화를 한 문장에 씀. "~ 처리 세포에서 ~은 처리 용량과 시간에 의존적으로 감소하였다"(N3)
- 해석: "~ 향상된 것으로 판단된다", "~ 반응으로 인한 것으로 판단된다"(N2, N5)
- "핵심", "중요한 역할"은 연구 대상(단백질, 반응)을 서술하는 말로 쓰임(N3에서 7회, 6회). 이 분야에서는 LLM 문체 표지로 단정하지 않고 문맥을 봄

### data (D1~D5)

- 통계 방법(응용통계연구): 서론 / 방법(모형, 추정량) / 모의실험 / 실제 자료 분석 / 결론(및 제언) (D1, D4)
- 산업공학·경영(한국산업경영시스템학회지, 품질경영학회지): 서론 / 이론적 배경 또는 문헌 연구 / 연구 설계·문제 정의 / 실험 및 결과 / 결론 (D2, D3, D5)
- 정의와 가정: 현재형으로 씀. "~을 ~으로 정의한다", "Case 3은 ~을 가정한다"(D2, D5)
- 설정값: 근거와 함께 씀. "가중치는 ~에 더 많은 중요도를 부여하기 위해 ~에 반비례하도록 설정하였다"(D4), "~의 탐색 범위는 ~의 최솟값과 최댓값으로 설정하였다"(D3)
- 결과: 모의실험은 "~이 ~ 중에서 가장 우수한 추정량임을 알 수 있다"(D1), 실증 분석의 해석은 "~ 때문으로 판단된다/보인다"(D4)
- 문두 접속어 비율이 가장 높음(중앙값 18%)

## 4. 분야와 관계없이 지킬 것

- "~에 의해" 피동은 30편 중 22편에 있었으나(합계 82회, M5 18회) 번역투로 읽히므로, 능동형으로 쓸 수 있으면 바꿈(phrasebank 7절)
- 영문 그림 번호(Fig.)와 한글 그림 번호(그림)는 투고처 집필 요령을 따르고, 한 원고 안에서 섞지 않음
